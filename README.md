# 大乐透数据中心（本地版）

只聚焦**中国体育彩票 · 超级大乐透**的本地数据站。包含最新开奖、历史期号查询、多图表走势分析，以及基于 AI 多维集成 / 宇宙通识常量 / 混沌动力学 / 马尔可夫链 / 生日 + 时间 / 随机的**多组下期号码预测**。

## 快速启动

要求：Node.js 18 或更高版本（本机已验证 Node 24）。

```bash
# 方式一：运行启动脚本
./start.sh

# 方式二：npm
npm start
```

打开：

**http://127.0.0.1:8787**

自定义端口：

```bash
PORT=9000 ./start.sh
```

局域网访问（请确认网络环境安全）：

```bash
HOST=0.0.0.0 PORT=8787 ./start.sh
```

## 功能

### 开奖大厅

- 超级大乐透最新一期开奖号码、奖池、销量、下期停售倒计时。
- 最近开奖列表：分页浏览、按期号检索、点击查看奖级明细。
- 快速核对：输入前区 5 个 + 后区 2 个号码，与最新一期比对并提示参考奖级。

### 历史走势（9 种视图）

- 前区号码出现频率（01-35）
- 后区号码出现频率（01-12）
- 前区跨度走势
- 前区和值走势（折线 + 周期均值）
- 奇偶结构环形图
- 大小结构环形图
- 五区分布
- 当前遗漏排行
- 近 30 期号码矩阵（可横向滑动）

支持切换近 30 / 50 / 100 期。所有图表在本机用原生 SVG / CSS 绘制，不依赖第三方图表库。

### 下期预测

- 固定生成 5 组号码，每组前区 5 个 + 后区 2 个。
- 六种策略可多选：
  - **AI 多维集成**：近 10 期趋势 / 马尔可夫转移 / 邻号引力 / 混沌轨迹 / 宇宙常量 五维归一化加权。
  - **宇宙通识常量**：π、e、φ、√2、α⁻¹、c、h、Nₐ、G、k_B、qₑ 共 11 个常量的数字流映射，斐波那契数 ×φ、素数 ×α⁻¹。
  - **混沌动力学**：logistic 映射 720 步轨迹落桶，初值由上期号码与期号耦合。
  - **马尔可夫链**：相邻两期号码转移矩阵，从上期号码出发采样。
  - **生日 + 今日时间**：把生日、当前日期时间混合成随机种子。
  - **随机灵感**：使用浏览器随机源生成对照组合。
- 原「历史热度」「遗漏回补」两个策略已下线（历史批次仍按标签回显）。
- 每组显示预测策略、和值、奇偶 / 大小结构、跨度和生成依据。
- 支持复制单组或全部号码。
- **生日记忆**：选好「你的生日」即自动保存，下次打开预测页会在输入框下方显示「上次输入」的日期与保存时间，可点「填入」一键回填。主存储为服务端 `data/user-settings.json`（换浏览器、重启服务都还在），浏览器 `localStorage` 做即时写入与接口不可用时的降级；本次修改不会改写当前显示行，下次打开才更新，保证「上一次」的语义。
- **生成即存档**：号码生成后立即写入 `data/predictions.json` 并锁定，本期不再变动（原「换一批」已移除）。
- **开奖自动结算**：下一期开奖后自动拉取官方号码，逐组标记命中球、命中个数与奖级，中奖信息显示在预测页顶部与每组卡片上。
- **历史预测记录**：预测页底部列出最近批次的期号、生成时间、组数与中奖结果，最多保留 60 期。

> 重要：彩票开奖是独立随机事件，历史走势和生日组合都不能提高中奖概率。预测功能只用于娱乐和选号灵感，不构成任何投注建议，也不承诺中奖。

## 数据来源

- 开奖数据来自中国体彩网公开接口 `webapi.sporttery.cn`。
- 后端每 30 秒内复用缓存，页面每 30 秒自动刷新最新开奖；手动刷新会强制拉取上游。
- 成功同步的快照保存在 `data/overview-cache.json`，网络异常时用于兜底。
- 奖级规则按超级大乐透现行 7 个奖级计算参考奖级（未区分追加投注）。
- 开奖结果、奖级和兑奖信息以中国体育彩票官方最终公布为准。

## 接口

| 接口 | 说明 |
| --- | --- |
| `GET /api/overview` | 大乐透最新一期 |
| `GET /api/history?page=1&pageSize=10` | 历史开奖分页 |
| `GET /api/draw?issue=26123` | 指定期号详情（`issue=latest` 取最新） |
| `GET /api/analysis?limit=50` | 走势聚合数据（频率、遗漏、和值、结构、矩阵等） |
| `GET /api/predictions` | 预测批次列表（含自动结算后的中奖信息） |
| `POST /api/predictions` | 保存一批下期预测号码（生成即锁定） |
| `GET /api/settings` | 读取上次输入的生日 `{ lastBirthday, updatedAt }` |
| `POST /api/settings` | 保存上次输入的生日，body：`{ "lastBirthday": "YYYY-MM-DD" }`（校验格式、拒绝未来日期） |
| `GET /api/health` | 健康检查 |
